# Despertar PΨ — Landing Page

Site institucional da **Despertar PΨ — Parapsicologia Clínica e Terapias
Integrativas** (Marco Sadério).

Feito com Next.js 16 + TypeScript + Tailwind v4. Site estático, hospedado
na Vercel.

## Documentação

- **[COMO-EDITAR.md](./COMO-EDITAR.md)** — guia para o Marco editar
  textos, depoimentos e fotos sem programar.
- **[MANUTENCAO.md](./MANUTENCAO.md)** — guia técnico: rodar, publicar,
  domínio, leads, analytics e Google.

## Rodar

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # versão de produção
```

Todo o conteúdo editável vive em [`src/content`](./src/content).
